KREW 1.0.0-rc.1
================
1. Останови старую версию KREW.
2. Перенос с 0.6.0: python upgrade.py "C:\путь\к\KREW_Bot_0.6.0"
3. Создай .env из .env.example, если его ещё нет, вставь новый BOT_TOKEN.
4. Проверь: python release_check.py
5. Запусти: python main.py
6. В группе: /diagnostics и /setup
7. В личке: /start, /panel, /myreports, /notify on|off
Для Mini App нужен WEBAPP_URL=https://адрес сервера.
Подробно: README.md и RELEASE_CHECKLIST.md
